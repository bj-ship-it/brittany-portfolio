# Brittany Alley — Portfolio

Open this brittany-portfolio folder in VS Code and run index.html with Live Server. The portfolio folder must be the server root. Open through HTTP, not by double-clicking the HTML files.

## Bitz Up demo
The demos/bitz-up folder is a static Next.js export built from the supplied copy.zip. The original author pages, profiles, map interactions, navigation, fonts, and supplied graphics are retained. Account and ticket data are local fixtures using alex@example.com and clearly marked demo IDs. Authentication screens are replaced with a demo entry page; no Supabase client or credentials are used. Map choices are stored only in this browser under a portfolio-specific key. Public author and event content reflects the supplied project snapshot, not a guarantee of current event details. External author and merchandise links still open their actual destinations.

The compiled demo uses /demos/bitz-up as its base path. Hosting beneath a GitHub repository subdirectory requires rebuilding for that path before publishing.
